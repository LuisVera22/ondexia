Catálogo de los siete componentes transversales construidos en la Etapa 0. Referencia interna: se elimina antes de publicar.

selector-contexto

Empresa y establecimiento activos. Con una sola opción se muestra como texto fijo.

estado-comprobante

Borrador es el único con borde punteado: se reconoce como editable sin leer el texto.

@for (estado of estados; track estado) { }

buscador-entidad

Escriba para desplegar. Se recorre con las flechas y se confirma con Enter.

tabla-datos

Ordenamiento, selección múltiple y paginación. Los importes van a la derecha.

pagina-vacia

El estado vacío explica qué es la sección y ofrece la acción para empezar.

editor-lineas

El componente P3. Cambie cantidades o afectación y los totales se recalculan.

confirmacion

Solo para acciones irreversibles. Usarlo en todo entrena a aceptar sin leer.
